## html-to-php — Project Layout

**[Emerging] (ny-mag-ag)** — multi-page PHP blog magazine converted from a clean Bootstrap HTML template, PDO-backed, multi-tenant (rows filtered by a site-slug column), clean URLs via `.htaccess` (Apache mod_rewrite).

**[Emerging] (ny-mag-ag)** — Every non-public subfolder (`includes/`, `functions/`, `blogs_on/`, `feed/`, `sitemaps/`, every level of `assets/`) contains an `index.php` running `header("location: ../"); exit();` to prevent directory listing.

### Clean URLs (via `.htaccess`)

The `.htaccess` at the project root implements all routing. It is shipped with the deliverable. Key behaviours:

- Blocks non-GET/POST/HEAD methods (405).
- Strips trailing slashes (301 redirect).
- Security headers: `X-XSS-Protection`, `X-Frame-Options SAMEORIGIN`, `X-Content-Type-Options nosniff`, `Strict-Transport-Security`, `Referrer-Policy`, `Feature-Policy`.
- `Options All -Indexes` — disables directory browsing at the Apache level (complementing the `index.php` redirect stubs in every subfolder).
- Denies direct HTTP access to `.htaccess` itself.
- `ErrorDocument` for 400/401/403/404/500 → `/404-page`.
- Commented-out www-redirect and HTTPS-redirect rules — present but disabled, intended to be toggled for production.

Rewrite rules:

| Clean URL                        | Target                                          |
|----------------------------------|-------------------------------------------------|
| `/`                              | `index.php` (implicit — no rewrite needed)      |
| `/home`                          | `index.php`                                     |
| `/about-us`                      | `about.php`                                     |
| `/contact-us`                    | `contact.php`                                   |
| `/privacy-policy`                | `privacy-policy.php`                            |
| `/our-blogs`                     | `our-blogs.php` (supports `?page=N`)            |
| `/search-result`                 | `search.php` (passes `?searchQuery=…` through)  |
| `/404-page`                      | `404.php`                                       |
| `/cat-<slug>`                    | `category.php?cat_url=<slug>`                   |
| `/cat-<slug>-page-<n>`           | `category.php?cat_url=<slug>&page=<n>`          |
| `/auth-<slug>`                   | `single-author.php?auth_url=<slug>`             |
| `/blogs_on/<slug>`               | `blogs_on/blog_details.php?blog_url=<slug>` (real directory — no rewrite needed) |
| `/feed/rss`                      | `feed/rss.php` (real directory — no rewrite needed) |

### Globals defined in `includes/database.php`

- **DB:** `$con` (PDO, utf8mb4, `ATTR_ERRMODE = ERRMODE_EXCEPTION`)
- **Tenant key:** site-slug global (e.g. `$wiscoy_webSlug`) — every blog query filters `WHERE my_web_url = ?` with it
- **URLs:** `$wiscoy_url` (env-switched site base); `$reverbURL = "https://www.reverbtimemag.com/"` (cross-site image host, placed after env block before try/catch)
- **Brand:** `$shortTitle`, `$adm_email` (`admin@<domain>`), social URLs built from `website_slug` (e.g. `$adm_facebook = "https://www.facebook.com/<slug>"`), `$adm_desc`, `$adm_keywords` (main_categories + ", magazine, blog, articles"), contact info
- **`$myTopNiche`** — `"AND \`blog_category\` NOT IN ('<cat1>', '<cat2>', ...)"` built from ALL `site.main_categories` in features.yaml. Never an empty string.
- **`$greyNiche`** — `"AND \`blog_category\` NOT IN ('cbd', 'casino', 'vape', 'essay-writing', 'relationship', 'beverage')"`. Same for every project.
- **Helper:** `extractCleanUrl($url)` — strips query string for canonical URLs

### Tables referenced

The database is the shared **`reverbtime`** multi-tenant DB. The full structure dump is at `tests/fixtures/reverbtime.sql`; the tables actually consumed by the html-to-php pipeline are listed below. Only `blog` and `blog_views` carry a `my_web_url` column — those are the tenant-filtered tables. `author` and `admin` are global lookup tables.

- **`blog`** — main articles. Columns: `blog_id`, `admin_id`, `blog_title`, `blog_h1`, `url_slug`, `my_web_url`, `blog_author`, `blog_category`, `blog_image`, `blog_shortDesc`, `blog_keywords`, `blog_content`, `blog_date`.
- **`blog_comments`** — `comment_id`, `blog_url`, `user_key`, `comment_name`, `comment_email`, `comment`, `comment_date`.
- **`blog_views`** — `blgView_id`, `user_ip`, `user_sessKey`, `current_page`, `my_web_url`, `user_device`, `upload_date`.
- **`author`** — `author_id`, `author_slug`, `author_email`, `author_password`, `author_name`, `author_phone`, `login_type`, `token`, `author_img`, `trusted_author`, `account_status`, `register_date`. No `my_web_url` — not tenant-filtered.
- **`admin`** — `admin_id`, `admin_email`, `admin_password`, `company_fullname`, `company_url`, `company_title`, `company_tagline`, `company_address`, `company_address_2`, `company_email_1`, `company_email_2`, `company_phone_1`, `company_phone_2`, `last_login`. No `my_web_url`. Used as the fallback author source for slugs whitelisted in `$validAuthURLs` (lookup is via `company_url`).

The reverbtime dump contains additional tables (`blog_check`, `blog_credit`, `blog_pay`, `blog_pending`, `contact`, `csr_images`, `link_insertion`, `meta`, `music`, `sorted_blogs`, `unique_vts`) that other tenants on this DB use but the ny-mag-ag html-to-php deliverable does not.

### Page template

```php
<?php
ini_set("session.cookie_httponly", 1);
session_start();
include("./includes/database.php");
include("./functions/functions.php");

// (optional) $pgKey = "home";  — load meta from $pgMeta in includes/meta.php
// OR explicitly set: $_neuPgTitle, $_neuPgKeywords, $_neuPgDesc1, $_neuPgSiteName,
//   $_nuRobotIndex1, $_nuRobotFollow1, $can_pageUrl, $_neuPgImg
?>
<!DOCTYPE html>
<html class="no-js" lang="en">
<head>
<?php include("./includes/head.php"); ?>
</head>
<body class="mobilemenu-active">
    <?php include("./includes/preloader.php"); ?>
    <div id="main-wrapper" class="main-wrapper">
        <?php include("./includes/header.php"); ?>
        <!-- page-specific sections here -->
        <?php include("./includes/footer.php"); ?>
    </div>
    <?php include("./includes/section-4.php"); ?>
</body>
</html>
```

Subfolder pages (`blogs_on/blog_details.php`, `feed/rss.php`, `sitemaps/*.php`) use `../includes/…` instead of `./includes/…`.
